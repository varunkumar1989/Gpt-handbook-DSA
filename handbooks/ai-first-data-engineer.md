# AI-First Data Engineer

## Outcome

Build reliable data products from spreadsheet analysis through SQL, BI, Python, machine learning and responsible GenAI workflows.

## Curriculum map

| Stage | Topics | Portfolio evidence |
|---|---|---|
| Excel | Foundations, formulas, text/date cleaning, validation, lookups, pivots, dashboards, Power Query | Clean data workbook and executive dashboard |
| SQL | ERDs, DDL/DML, filters, aggregates, joins, windows, CTEs, quality checks | Reusable ecommerce KPI query pack |
| Power BI | Power Query, star schema, DAX, visuals, drill-through, forecasting | Refreshable semantic model and report |
| Python | Jupyter, data structures, functions, files, NumPy, Pandas, visualisation, statistics | Reproducible analysis notebook |
| Machine learning | Framing, preprocessing, regression, classification, KNN, validation, RFM, model evaluation | Model card and error analysis |
| AI-first engineering | Prompting, RAG, agents, AI in BI/SQL, data lineage, reverse engineering and FDE | Grounded data assistant design |

## Lesson workflow

For each class or topic:

1. Write the business question and expected decision.
2. Rebuild the example with permitted or synthetic data.
3. Document source, data grain, transformation logic and validation.
4. Use AI only as a collaborator: explain, generate edge cases or review.
5. Save a visible proof: workbook, query, dashboard, notebook, prompt test or README.

## Core projects

### 1. Ecommerce analytics pack
- Create an Orders fact table and supporting Customer/Product dimensions.
- Clean and profile data in Excel or Power Query.
- Write SQL for revenue, repeat purchase, basket size, top products and data quality.
- Create a Power BI dashboard with KPI definitions and a refresh note.

### 2. Python data science notebook
- Profile missingness, duplicates, distributions and outliers.
- Create features and report the transformations.
- Test a business hypothesis carefully.
- Visualise results and include limitations.

### 3. ML decision workflow
- Define target, baseline, error cost and scope.
- Split data before preprocessing.
- Use a pipeline and cross-validation.
- Compare models and explain errors, limits and monitoring needs.

### 4. Grounded data assistant
- Use permitted documents or synthetic data only.
- Add source citations or validated tool results.
- Build a ten-question evaluation set.
- Define access controls, prompt-injection defenses and human approval rules.

## Responsible reverse engineering and FDE

Reverse engineering means observing a system and documenting its visible behavior or interfaces. It must not involve copying proprietary code, bypassing access restrictions or violating terms. A safe output is a requirements brief that separates observed behavior, evidence and assumptions.

Forward Deployed Engineering (FDE) applies technical delivery close to real user workflows. It emphasizes discovery, integration, data contracts, adoption and measurable outcomes. A strong FDE project includes an owner, user journey, source permissions, interface contract, operating workflow and support plan.

## Completion checklist

- [ ] Business question is clear.
- [ ] Data is permitted and its grain is documented.
- [ ] Transformations and metrics are reproducible.
- [ ] Output is validated against known totals or test cases.
- [ ] Assumptions and limitations are visible.
- [ ] AI output is evaluated, cited or rejected when unsupported.
- [ ] README explains how to run, interpret and improve the work.
