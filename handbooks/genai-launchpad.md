# GenAI Launchpad

## Outcome

Learn to build useful, grounded and testable GenAI workflows rather than relying on one-off chat prompts.

## Core sequence

1. **GenAI landscape** - models, tokens, context, modalities, uncertainty and use-case selection.
2. **Prompt architecture** - role, task, context, constraints, examples, output schema and rubric.
3. **Data prompts** - schema grounding, cited metrics, structured output and unknown-value behavior.
4. **Evaluation** - golden sets, rubrics, adversarial prompts, regression tests and human review.
5. **RAG** - chunks, embeddings, retrieval, citations, permissions and freshness.
6. **Tools** - function calling, JSON schemas, validation and safe retries.
7. **Agents** - tool contracts, handoffs, state, approval gates, logs and stop rules.
8. **Safety** - privacy, secrets, prompt injection, access controls and escalation.
9. **Data workflows** - AI-assisted Excel, SQL, BI and Python with traceable verification.
10. **Portfolio build** - a grounded assistant with tests, a demo and an honest README.

## Prompt card

Use this pattern:

- **Context:** approved facts, source text or synthetic schema.
- **Task:** one precise action.
- **Constraints:** what the model must not do.
- **Output:** table, JSON schema or another checkable format.
- **Evidence:** cite source or mark the answer unknown.
- **Evaluation:** state what makes the output pass.

## Ten-day mini-product sprint

| Day | Deliverable |
|---|---|
| 1 | One user, one decision and a measurable outcome |
| 2 | Permitted source and access plan |
| 3 | Prompt v1 plus output schema |
| 4 | Ten realistic evaluation questions |
| 5 | Retrieval or tool design |
| 6 | Privacy, injection and escalation review |
| 7 | Evaluation run and failure analysis |
| 8 | One focused improvement and re-test |
| 9 | Demo and README |
| 10 | Feedback, limitations and roadmap |

## Definition of done

A good GenAI project includes a real user problem, a controlled workflow, permitted data, a small evaluation set, visible sources, failure behavior and a human approval point for high-impact actions. The goal is trustworthy usefulness, not maximum autonomy.
