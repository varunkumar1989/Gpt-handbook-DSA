# Practice and resource index

Use public resources for learning and verify product-specific behavior against the official documentation.

## Data and analytics

- [W3Schools](https://www.w3schools.com/) - tutorials, examples, exercises and quizzes for Excel, SQL, Python, DSA and related topics.
- [Microsoft Excel Help](https://support.microsoft.com/excel) - official Excel support.
- [Microsoft Learn: Transact-SQL](https://learn.microsoft.com/en-us/training/paths/program-transact-sql/) - structured SQL learning path.
- [Microsoft Learn: Power BI](https://learn.microsoft.com/training/powerplatform/power-bi/) - Power BI modules.
- [Tableau Training](https://www.tableau.com/learn/training) - official Tableau learning.
- [Python Tutorial](https://docs.python.org/3/tutorial/) - official Python tutorial.
- [Pandas User Guide](https://pandas.pydata.org/docs/user_guide/) - tabular data work.
- [scikit-learn Getting Started](https://scikit-learn.org/stable/getting_started) - applied machine learning.
- [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course/) - ML concepts and practice.
- [dbt Learn](https://docs.getdbt.com/learn) - analytics engineering and data transformation.

## GenAI and agents

- [OpenAI developer guides](https://developers.openai.com/) - current API and product documentation.
- [Prompt engineering guide](https://developers.openai.com/api/docs/guides/prompt-engineering) - prompting techniques and evaluation habits.
- [OpenAI Agents](https://developers.openai.com/learn/agents) - agentic workflow concepts.
- [OpenAI practical guide to building AI agents](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/) - design and operating guidance.
- [OWASP GenAI Security](https://genai.owasp.org/) - security concerns and controls for GenAI applications.
