# AI-First Data Engineer Handbooks

A practical learning library curated by Varun Kumar.

This repository is the information home for the AI-First Data Engineer and GenAI Launchpad learning paths. It is intentionally focused on readable curriculum, projects, practice links and responsible AI workflows. No private LMS content, credentials or restricted datasets are included.

## Learning paths

- [AI-First Data Engineer handbook](handbooks/ai-first-data-engineer.md) - Excel, SQL, Power BI, Python, statistics, machine learning, data engineering and responsible AI.
- [GenAI Launchpad handbook](handbooks/genai-launchpad.md) - prompting, evaluation, RAG, structured outputs, agents, safety and an end-to-end portfolio project.
- [Practice and resource index](resources.md) - official documentation, guided practice and discovery resources.

## Recommended learning workflow

1. Choose a path and complete one lesson page at a time.
2. Rebuild every example with permitted or synthetic data.
3. Save one proof per lesson: a query, notebook, dashboard, prompt evaluation or README.
4. Use AI to explain, test and review; validate all results yourself.
5. Publish only work you are allowed to share.

## Portfolio evidence

A strong data and AI project makes its question, data grain, transformations, validation, results, limits and next action easy to inspect. For GenAI projects, also keep prompt versions, a small evaluation set, citations and approval rules.

## Source PDFs

The companion PDFs are prepared locally as downloadable artifacts for the learner. The detailed curriculum and all public resource links are preserved in this repository so the material remains easy to browse and version.

## Safety note

Do not paste credentials, personally identifiable information or proprietary datasets into public AI tools. Use official product documentation to confirm current features and limits.
